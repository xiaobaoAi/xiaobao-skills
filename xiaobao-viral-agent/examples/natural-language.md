# 自然语言任务示例

以下用例供 Agent 路由与自测。用户话术 → 期望模式 → Agent 应做的事（对用户不可见内部 ID）。

---

## 1. 数字人口播

**用户：** 「帮我做一条数字人口播」

- 模式：`realMan`
- 追问（若缺）：口播文案或口播视频链接、形象/人物、竖屏还是横屏、风格
- 自动：list-templates(realMan) → 选模版 →（必要时 TTS/数字人）→ create → poll
- 交付：成片链接

**用户：** 「帮我做一条 30 秒老板口播视频，竖屏，稳重点」

- 模式：`realMan`
- 抽取：时长≈30s、人物=老板、画幅=竖屏、风格=稳重
- 若无视频/文案：先要文案或口播素材链接

---

## 2. 素材混剪

**用户：** 「帮我把文案和素材做成视频」

- 模式：`oralMixCutting`
- 追问：文案正文、素材 https 链接、风格/平台
- 自动：TTS（若无音频）→ list-templates(oralMixCutting) → create → poll

**用户：** 「把这段文案配成声音，再和图片混剪」+（文案与图片 URL）

- 模式：`oralMixCutting`
- 自动：TTS → 混剪；声音偏好不明时可问「女声还是男声」等，不问 voice_id

---

## 3. 新闻混剪

**用户：** 「帮我做一个新闻混剪」

- 模式：`newsMixCutting`
- 追问：新闻标题/事件一句话、素材图或视频链接
- 自动：list-templates(newsMixCutting) → create → poll

**用户：** 「把这个新闻做成资讯短视频」+ 标题与素材

- 模式：`newsMixCutting`
- 标题写入主题；不要按口播去要长文案（除非用户给了）

---

## 4. 视频包装

**用户：** 「帮我给这个视频加字幕和包装」+ 视频 URL

- 模式：`videoPackaging`
- 自动：recognize 字幕 → list-templates → create → poll

**用户：** 「把这个视频加字幕和科技感包装」+ 视频 URL

- 模式：`videoPackaging`
- 选模版时偏向名称/标签含科技、未来感等；用人话确认「已按科技感风格处理」

---

## 5. 需澄清（不要猜错）

**用户：** 「帮我做个短视频」

- 不硬选模式
- 问：「更想要人物出镜口播、文案配音叠素材、新闻资讯，还是给已有视频加包装？」
