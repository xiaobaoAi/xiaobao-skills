# 错误转译（对用户可见文案）

脚本或接口返回的英文/字段名，必须转成中文后再给用户。可保留「建议动作」，不要甩原始 JSON（除非用户明确要求排障）。

## 凭据与权限

| 信号（内部） | 对用户说 |
|--------------|----------|
| 未找到 credentials / 缺少 api_key | 还没有配置开放平台密钥。请先申请 Key，并在本机执行凭据配置。 |
| 401 / unauthorized / key 无效 | 密钥无效或已失效，请到开放平台检查后更新本机凭据。 |
| 403 / 无权限 / 未开通 | 当前账号没有该功能权限，请到开放平台开通对应能力。 |
| 余额 / 点数 / 欠费 | 余额或点数不足，请充值后再试。 |

## 模版与素材

| 信号 | 对用户说 |
|------|----------|
| 模版列表空 / style 不存在 | 暂时没有匹配到合适风格模版。请换一种风格描述，或稍后再试。 |
| 素材 404 / 无法下载 / invalid url | 素材链接打不开。请换成浏览器能直接打开的 https 地址。 |
| 本地路径 | 本地文件会先走 [文件上传](https://apis.xiaobao.ink/doc/49) 换成公网地址；配额不足时请清理空间或充值。 |
| 格式/编码不支持 | 视频请用 mp4 或 mov（H.264/HEVC）；图片 jpg/png/webp；音频 mp3/wav/m4a。详见 [media-requirements.md](media-requirements.md)。 |
| 时长超限 | 口播主视频须短于 5 分钟；单条素材视频须 ≤60 秒；全部素材合计 ≤5 分钟（图按 2 秒/张）。请裁剪后再试。 |
| 文件过大 | 主视频/素材视频 &lt;500MB；音频 ≤120MB；封面 ≤10MB。请压缩后重传。 |
| 分辨率过大 | 画面单边分辨率须小于 2000px。 |
| 无可用人声 | 口播/包装用的主视频需要能转写的人声，请换一段带清晰旁白的成片。 |
| media_requirements（create 拦截） | 素材不符合智能剪辑要求，已停止提交。请按 media-requirements.md 调整后再试。 |

## 参数与任务

| 信号 | 对用户说 |
|------|----------|
| 缺少文案/标题/素材 | 还差必要信息：{用人话列出缺失项}。 |
| create 失败 + msg | 提交生成失败：{转述 msg}。请对照 [media-requirements.md](media-requirements.md) 检查格式、时长与大小。 |
| poll 失败 / fail_reason | 生成未成功：{转述原因}。可尝试换风格模版，或裁剪/更换不合规素材后重试。 |
| 轮询超时 | 等待超时，生成可能仍在排队。请用同一任务号再查，或加长 `--attempts`；也可缩短目标时长、减少素材。 |

## 原则

1. 不展示 `api_key`、完整请求体、内部 ID（除非用户要排障）。
2. 一条失败对应「原因 + 建议」，避免技术黑话。
3. 可同时给出开放平台入口：https://apis.xiaobao.ink/
