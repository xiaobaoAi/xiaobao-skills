# 智能剪辑 · 素材与媒体要求

来源：[真人口播 doc/25](https://apis.xiaobao.ink/doc/25)。口播混剪 / 新闻混剪 / 视频包装与真人口播共用同一套媒体约束。  
**不合规素材会直接生成失败。** 创建任务前必须按本表核对；不确定时先追问或换素材，不要硬提交。

---

## 口播成片 / 主视频 `videoUrl`（realMan、videoPackaging）

| 项 | 要求 |
|----|------|
| 格式 | `mp4`、`mov` |
| 编码 | H.264、HEVC（H.265） |
| 帧率 | 10～60 fps，推荐 **25** |
| 分辨率 | 单边 **&lt; 2000px** |
| 时长 | **&lt; 5 分钟** |
| 大小 | **&lt; 500MB** |
| 音频 | 片中音频须能语音转文本（清晰人声，避免纯 BGM/无声） |

---

## 画面素材 `materials[]`

**总量：** 单张图片按 **2 秒** 计；单个视频素材 **≤ 60 秒**；所有素材合计时长 **≤ 5 分钟**。

### 图片

| 项 | 要求 |
|----|------|
| 格式 | `jpg` / `jpeg`、`png`、`webp`（静态图） |
| 分辨率 | 单边 **&lt; 2000px** |

### 视频素材

| 项 | 要求 |
|----|------|
| 格式 | `mp4`、`mov` |
| 大小 | 单个 **&lt; 500MB** |
| 分辨率 | 单边 **&lt; 2000px** |
| 时长 | 单个 **≤ 60 秒**（且计入总时长 ≤ 5 分钟） |

---

## 背景音乐 / 旁白音频 `audioUrl`

| 项 | 要求 |
|----|------|
| 格式 | `mp3`、`wav`、`m4a` |
| 大小 | **≤ 120MB** |
| 时长 | **≤ 5 分钟** |

---

## 首帧封面 `imageUrl` / `resultImageUrl`

| 项 | 要求 |
|----|------|
| 格式 | `jpg` / `jpeg`、`png` |
| 大小 | **≤ 10MB** |
| 分辨率 | 单边 **&lt; 2000px** |

---

## Agent 执行清单（提交前）

1. URL 可公网访问；本地文件先 `upload.mjs`（[doc/49](https://apis.xiaobao.ink/doc/49)）。
2. 扩展名落在上表白名单（不要传 webm / avi / gif 动图 / flac 等）。
3. 能拿到的文件大小若超限，换压缩后再传。
4. 视频时长、帧率、编码、分辨率若用户未知，提醒按「推荐 25fps、H.264、单边 &lt;2000、口播片 &lt;5 分钟」准备；明显超长（如 10 分钟成片）先裁切。
5. 素材很多时估算：图片数 × 2 秒 + 各视频秒数 ≤ 300 秒；单条素材视频 &gt; 60 秒先剪短。
6. `videoUrl` 必须有可识别人声（包装/口播），否则 ASR/字幕链路会失败。

校验脚本：`node scripts/validate-media.mjs --mode realMan --input payload.json`（扩展名与已知大小；时长/编码需人工或 ffprobe）。
